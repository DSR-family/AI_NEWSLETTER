Strategic Radar

커넥터의 핵심은
AI가 데이터를 직접
찾아보게 만드는 것입니다

매번 파일을 업로드하지 않아도 됩니다. '커넥터' 기능은 Google Drive, GitHub 같은 사내 도구를 AI와 미리 연결해두고, 이후 질문할 때 AI가 그 안의 데이터를 직접 찾아 답변에 활용하게 합니다.

The Leader's Role

Claude Team plan의 경우 데이터가 모델 학습에는 쓰이지 않지만, 개인정보·제3자 공유 금지 자료 등은 별개 문제입니다. 연결하기 전에 무엇을 올려도 되고, 무엇은 안 되는지를 리더가 먼저 정해야 합니다.

Team Workflow 해독기

커넥터로 무엇을 할 수 있는가

커넥터의 효과는 연결 개수보다 어떤 용도로 쓰느냐가 결정합니다. 리더는 먼저 자료검색형·진행현황 조회형·기록정리형을 구분해야 합니다.

📁

자료검색형

Google Drive 등 문서저장소

필요한 문서를 즉시 찾는 연결

설계 도면, 품질 기록, 계약서처럼 폴더 깊숙이 흩어져 있던 문서는 커넥터로 AI가 직접 찾게 만듭니다. 목적은 파일을 모아두는 것이 아니라 AI가 우리 문서고를 직접 뒤져 답을 찾게 만드는 것입니다.

이럴 때: 도면·품질기록 검색, 계약서·규정 조회, 과거 보고서 찾기

📋

진행현황 조회형

GitHub 등 업무관리 도구

진행현황을 확인하는 연결

과제 진행률, 이슈 상태, 담당자별 처리 현황처럼 시스템에 접속해야만 보이던 정보를 커넥터로 AI가 바로 조회하게 만듭니다. 목적은 현황판을 대신 보는 것이 아니라 같은 질문에 항상 최신 현황이 돌아오게 하는 것입니다.

이럴 때: 과제·이슈 진행 현황, 담당자별 처리 상태, 일정 지연 확인

💬

기록정리형

이메일 등

흩어진 대화를 정리하는 연결

담당자 간 협의 내용, 놓친 메일처럼 받은편지함에 묻혀 있던 정보는 커넥터로 연결해 넣습니다. 핵심은 대화를 저장하는 것이 아니라 AI가 특정 사안에 대해 나눈 대화와 결론을 그대로 요약하게 하는 것입니다.

이럴 때: 특정 사안 논의 내용 확인, 놓친 메일 찾기, 협의 결론 정리

Connection Boundary

무엇을 연결해도 되는가

커넥터로 연결한 순간, 그 안의 모든 자료가 AI의 검색 대상이 됩니다.
연결 전에 폴더·채널 단위로 자유활용형·금지형을 구분해야 합니다.

* DSR은 Team 플랜을 사용해 모델 학습에는 자료가 쓰이지 않습니다. 다만 자료가 외부 서버로 전송된다는 사실 자체는 남기 때문에, 개인정보 포함 여부·계약상 제3자 공유 금지 여부·사내 접근 권한을 기준으로 판단해야 합니다. (사내 GitHub은 전 저장소가 private이며 각 팀은 자기 팀 저장소만 조회할 수 있어, 접근 범위는 이미 통제되어 있습니다.)

Screen Guide

커넥터는 실제로 이렇게 연결합니다

아래 순서를 따라 연결할 수 있습니다.

STEP 1) 프로필 → 설정 → 사용자 지정 → 커넥터

STEP 2) 커넥터 메뉴 → '연결' 버튼으로 연결

1 '연결' 버튼으로 원하는 도구 연결

목록에서 원하는 커넥터 옆의 '연결' 버튼을 누르면 바로 연결됩니다.

  • Google Workspace — Drive, Gmail, Calendar 등 문서·일정을 연결합니다.
  • GitHub — 이슈·과제 진행 현황을 연결합니다. (사내 GitHub은 저장소가 모두 private이고 팀별로 접근이 분리돼 있어 상대적으로 안전합니다.)

💡 연결 범위를 폴더 단위로 선택할 수 있는 도구라면, 필요한 폴더·채널만 골라 연결하세요.

2 커넥터는 어떻게 사용하나요?

연결이 끝나면 Claude가 사용자의 요청을 보고, 연결된 데이터와 관련이 있다고 판단되면 해당 커넥터를 자동으로 조회합니다. 특정 소스를 확실하게 지정하고 싶다면 대화창 왼쪽 아래 '+'를 눌러 커넥터를 직접 선택할 수도 있습니다.
